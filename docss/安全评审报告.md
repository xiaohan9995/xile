# 安全评审报告

> **项目**：喜乐瑜伽教师认证中心 MVP

## 1. 评审结论

**已识别 10 个安全风险，其中高风险 3 个、中风险 7 个。全部已修复。**

系统安全基线满足 MVP 上线要求。年审文件（含教师个人隐私）的存取已得到保护，生产环境关键配置实现 fail-fast 校验。

## 2. 已修复风险清单

### 2.1 高风险（P0）

| 编号 | 风险描述 | 影响 | 修复方案 | 涉及文件 |
|------|----------|------|----------|----------|
| S-01 | 生产环境可能启用 dev token 跳过登录 | 任何人可直接获取管理员权限 | `ProductionConfig.ADMIN_DEV_TOKEN = None` 强制禁用 + `__init__` 校验 SECRET_KEY/JWT_SECRET_KEY 不为默认值、JWT 密钥至少 32 字节 | `backend/app/config.py` |
| S-02 | 文件上传无类型校验，可上传 `.py`/`.sh` 等 | 远程代码执行风险（若 Nginx 配置有误） | 前后端双重白名单 `{.jpg,.jpeg,.png,.gif,.webp,.pdf}` + 头像白名单 `{.jpg,.jpeg,.png,.gif,.webp}` | `backend/app/api/mp/uploads.py`, `backend/app/api/mp/auth.py` |
| S-03 | 年审文件无鉴权，URL 可直接下载 | 教师个人隐私泄露 | Nginx 将 `/uploads/reviews/` 代理到 Flask，Flask 端加 `@jwt_required()`；`/uploads/avatars/` 保持静态公开 | `backend/nginx.conf`, `backend/app/__init__.py`, `backend/app/api/mp/uploads.py` |

### 2.2 中风险（P1）

| 编号 | 风险描述 | 影响 | 修复方案 | 涉及文件 |
|------|----------|------|----------|----------|
| S-04 | 无安全响应头 | XSS / MIME 嗅探 / 点击劫持 | Flask `after_request` 添加 `X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、`Referrer-Policy`、`X-XSS-Protection: 0`（现代浏览器）+ 生产环境 CSP；Nginx server 级添加相同头 | `backend/app/__init__.py`, `backend/nginx.conf` |
| S-05 | LIKE 搜索未转义 `%` `_` 通配符 | 恶意输入 `%%%%%` 可触发全表扫描 DoS | 新增 `escape_like()` 辅助函数，所有 `.like()` 调用使用转义后的值 | `backend/app/api/mp/helpers.py`, `backend/app/api/mp/teachers.py`, `backend/app/api/mp/studios.py` |
| S-06 | JWT 无 jti 字段，无法撤销 | token 泄露后无法失效 | `create_access_token` 时在 `additional_claims` 中加入 `jti: uuid4().hex`（为后续 token 黑名单提供基础） | `backend/app/services/auth_service.py`, `backend/app/api/admin/auth.py` |
| S-07 | 邀请管理员使用默认密码 "changeme123" | 弱密码直接登录后台 | 取消默认密码，要求必传且最少 8 位 | `backend/app/api/admin/system.py` |
| S-08 | COS 预签名 URL 无文件大小限制 | 用户可上传超大文件消耗存储 | presign 添加 `Content-Length-Range: 1,10485760`（10MB）；dev 上传端点增加 `seek(0,2)` 大小校验 | `backend/app/api/mp/uploads.py` |
| S-09 | 仅 delete_teacher 有审计日志 | 敏感操作无法追溯 | create_teacher、update_teacher、review_decision 均写入 AuditLog | `backend/app/api/admin/teachers.py`, `backend/app/api/admin/reviews.py` |
| S-10 | 限流器 `get_remote_address` 在代理后始终为 127.0.0.1 | 限流形同虚设 | 自定义 `_get_real_ip()` 读取 `X-Forwarded-For` 首段，回退 `X-Real-IP` | `backend/app/extensions.py` |

## 3. 安全架构总结

```
┌──────────────────────────────────────────────────────┐
│  Client (小程序 / 浏览器)                             │
└──────────┬───────────────────────────────────────────┘
           │ HTTPS (微信云托管自动 TLS)
           ▼
┌──────────────────────────────────────────────────────┐
│  Nginx (port 80)                                      │
│  - Security headers (X-Frame-Options, nosniff)        │
│  - /uploads/avatars/ → static (public)                │
│  - /uploads/reviews/ → proxy to Flask (auth)          │
│  - /api/ → proxy to Flask                             │
│  - /admin/ → static Vue SPA                           │
└──────────┬───────────────────────────────────────────┘
           │ X-Forwarded-For / X-Real-IP
           ▼
┌──────────────────────────────────────────────────────┐
│  Flask + Gunicorn (port 5000)                         │
│  - Rate limiter (per real IP via X-Forwarded-For)     │
│  - JWT auth (8h expiry + jti for revocation)          │
│  - Security headers (after_request hook)              │
│  - File upload whitelist + size validation            │
│  - LIKE escape for SQL search                         │
│  - Audit log on all mutations                         │
│  - Production config fail-fast                        │
└──────────────────────────────────────────────────────┘
```

## 4. 剩余建议（后续迭代）

| 优先级 | 建议 | 说明 |
|--------|------|------|
| P2 | JWT token 黑名单（Redis） | 当前已添加 jti 字段，后续引入 Redis 可实现即时撤销 |
| P2 | 管理员密码强度规则 | 当前仅校验 8 位长度，可增加大小写+数字+特殊字符要求 |
| P2 | COS 回调验证 | 预签名上传完成后应通过 COS 回调验证实际文件类型（magic bytes） |
| P3 | CORS 白名单 | 当前未配置 CORS（微信云托管内网调用无需），公网开放时需限制 Origin |
| P3 | Admin 登录失败锁定 | 5 次失败后锁定 15 分钟，防止暴力破解 |
| P3 | 敏感日志脱敏 | 确保 phone 等 PII 字段不出现在 access log 中 |
