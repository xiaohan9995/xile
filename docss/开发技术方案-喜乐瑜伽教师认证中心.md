# 喜乐瑜伽教师认证中心 — 开发技术方案

> **版本**：V1.0  
> **日期**：2026年6月16日  
> **状态**：开发基线  
> **依据**：《产品设计方案-喜乐瑜伽教师认证中心.md》《技术选型报告-喜乐瑜伽教师管理小程序.md》  
> **首期范围**：教师认证查询、教师本人认证与年审、管委会年审管理、教师资料维护、瑜伽工作室基础展示与维护。

---

## 1. 技术结论

首期采用 **小程序 + PC 管理后台 + Flask 后端 + TDSQL-C MySQL + 微信云托管单容器** 的方案。

| 层 | 技术方案 | 结论 |
|----|----------|------|
| 小程序 | 微信原生小程序 + Wot UI | 首期不做跨端，原生小程序最稳 |
| PC 管理后台 | Vue 3 + Vite + Element Plus | 管委会表格、审批、导入更适合 PC |
| 后端 | Python 3.10+ + Flask + SQLAlchemy | 业务以 CRUD、年审状态机、导入为主，Flask 足够 |
| 数据库 | TDSQL-C Serverless MySQL | 教师、年审、工作室是关系型数据 |
| 文件存储 | COS 或云托管对象存储 | 年审材料、证书图、工作室图片 |
| 部署 | 微信云托管单容器，Nginx + Gunicorn | `/admin` 静态后台，`/api` 后端接口 |
| 鉴权 | 小程序 OpenID + 管理端 JWT | 双端隔离，后端统一裁剪字段 |

不采用 uni-app/Taro、纯云函数、Spring Boot、自建 ECS。原因是首期没有跨端诉求，业务需要统一 API 和关系型数据，团队迭代效率优先。

## 2. 总体架构

```text
微信小程序
  ├─ 学员：教师查询、工作室查看
  └─ 教师：本人认证、年审申请、年审记录
       │ wx.cloud.callContainer
       ▼
微信云托管单容器
  ├─ Nginx :80
  │   ├─ /admin  → Vue 管理后台静态资源
  │   └─ /api    → Flask / Gunicorn
  └─ Flask API
      ├─ /api/mp/*
      └─ /api/admin/*
       │
       ├─ TDSQL-C MySQL
       └─ COS / 对象存储

PC 管理后台
  └─ https://xxx.run.tcloudbase.com/admin
       │ HTTPS /api/admin/*
       ▼
    Flask API
```

核心原则：

- 小程序只提供查询、自服务和申请，不提供管委会管理入口。
- 管委会所有写操作只走 `/api/admin/*`。
- 后台维护基础数据，前台按角色展示裁剪后的字段。
- 年审周期配置进数据库，不写死在前端。

## 6. 年审规则

| 档位 | 周期 |
|------|------|
| L0-L3 | 两年一审 |
| L4 | 三年一审 |
| L5 | 免审 |

实现方式：

- 周期配置保存在 `teacher_tiers.review_cycle_years`。
- L5 设置 `review_required = false`。
- 年审通过时，由后端根据档位周期计算 `next_valid_until`。
- 特殊教师如需覆盖周期，二期可在 `teachers` 增加 override 字段，首期不做。

## 8. 权限与安全

### 8.1 小程序

- 学员默认弱登录，只能看公开 DTO。
- 教师必须绑定 `teacher_id` 后，才能看本人详情和提交年审。
- 小程序端不能调用审批、导入、备注、教师编辑接口。

### 8.2 管理端

- 管理员账号登录后获取 JWT。
- JWT 有效期建议 8 小时。
- 首期角色只分 `admin` / `super_admin`。
- 所有管理端写操作写入 `audit_logs`。

### 8.3 字段裁剪

| DTO | 使用场景 | 字段原则 |
|-----|----------|----------|
| `TeacherSummaryDTO` | 学员/教师查他人 | 无手机号、无备注、无敏感身份信息 |
| `TeacherSelfDTO` | 教师本人 | 本人详细资料、年审状态、证书 |
| `TeacherAdminDTO` | 管委会后台 | 全字段、备注、附件、操作日志 |
| `StudioPublicDTO` | 小程序工作室 | 仅展示已开放工作室 |
| `StudioAdminDTO` | 管理后台 | 全字段、展示状态、资料完整度 |

## 10. 文件与上传

首期文件类型：

- 年审材料：PDF、图片。
- 教师证书：图片或 PDF。
- 工作室图片：图片。

建议策略：

- 文件先上传到私有对象存储。
- 数据库只保存文件 key、名称、类型、大小。
- 下载时由后端校验权限后返回临时访问链接。
- 小程序公开展示图可使用公开读或后端签名 URL，按实际云资源决定。

## 11. Excel 导入

导入流程：

1. 管理端上传 Excel。
2. 后端解析并生成预检结果。
3. 预检检查：必填字段、教师编号重复、档位是否合法、日期是否合法、手机号格式。
4. 前端展示错误行。
5. 管委会确认后写入 `teachers`、`teacher_details`。
6. 写入 `import_batches` 和 `audit_logs`。

首期不做自动合并复杂历史冲突。重复教师编号默认更新已有记录，具体策略需在拿到 Excel 后最终确认。

## 12. 部署方案

### 12.1 单容器

```text
Docker image
├── Nginx
│   ├── /admin → /var/www/admin
│   └── /api → 127.0.0.1:5000
└── Gunicorn
    └── Flask app
```

### 12.2 环境变量

| 变量 | 说明 |
|------|------|
| `FLASK_ENV` | `production` / `development` |
| `SECRET_KEY` | Flask/JWT 密钥 |
| `JWT_SECRET_KEY` | JWT 密钥，可与 Flask 分离 |
| `MYSQL_HOST` | 数据库地址 |
| `MYSQL_PORT` | 数据库端口 |
| `MYSQL_USER` | 数据库用户 |
| `MYSQL_PASSWORD` | 数据库密码 |
| `MYSQL_DATABASE` | 数据库名 |
| `COS_BUCKET` | 对象存储 bucket |
| `COS_REGION` | 对象存储地域 |
| `WECHAT_SERVICE_NAME` | 云托管服务名 |

### 12.3 Nginx 路由

```nginx
location /admin/ {
  root /var/www;
  try_files $uri $uri/ /admin/index.html;
}

location /api/ {
  proxy_pass http://127.0.0.1:5000;
  proxy_set_header Host $host;
  proxy_set_header X-Real-IP $remote_addr;
}
```

## 13. 测试策略

| 层 | 验证 |
|----|------|
| 后端 | pytest：年审周期、权限、导入预检、DTO 裁剪 |
| 小程序 | 微信开发者工具：页面跳转、搜索、教师绑定、提交年审 |
| 管理端 | 表格筛选、审核操作、工作室编辑、导入流程 |
| 部署 | Docker 本地验证 `/api/health` 与 `/admin` |

最低测试集：

- L0-L3 通过年审后有效期 +2 年。
- L4 通过年审后有效期 +3 年。
- L5 免审，不生成待审核任务。
- 学员无法访问教师详情敏感字段。
- 教师无法访问他人详情。
- 管理员审批写入审计日志。

- 工作室列表与详情。

- 教师绑定。
- 我的认证。

- Excel 预检与导入。
