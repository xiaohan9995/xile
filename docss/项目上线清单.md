## 1. 测试环境验证

- [ ] 管理后台可登录；教师、工作室、小程序用户、账号与权限等列表可正常加载、筛选、分页。
- [ ] 新增、编辑、删除操作正常；失败接口返回中文原因及 `requestId`。
- [ ] 教师和工作室头像/封面可展示、放大查看、上传后可回显。
- [ ] 小程序未登录时不能访问首页、工作室及教师服务；登录后可正常浏览。
- [ ] 微信首次授权登录可保存头像；在“我的”修改头像后，小程序用户及关联教师头像同步。
- [ ] 教师关联码生成、关联限制（一个教师仅关联一个小程序用户）和关联后跳转正常。
- [ ] 证书预览、查看大图、保存到相册均正常；相册授权拒绝后可跳转设置重新授权。
- [ ] 年审开放、未开放、未到期、已到期提交及后台审核流程符合预期。
- [ ] 工作室地图选点、地点搜索、城市/地区/地址自动回填、地址导航正常。
- [ ] 手工验证一次错误日志：使用返回的 `requestId` 能在云托管日志中找到对应记录。

## 2. 生产环境资源与配置

### 2.1 域名与访问

- [ ] 管理后台生产域名、API 域名已确定，并开启 HTTPS。
- [ ] 微信小程序“request 合法域名”“uploadFile 合法域名”“downloadFile 合法域名”已添加生产 API 域名。
- [ ] 若使用 CloudBase 容器调用，已同步校验对应环境 ID、服务名和访问路径。

### 2.2 云托管环境变量

在生产 CloudBase 云托管服务中设置，敏感值仅通过控制台或密钥管理维护：

| 变量 | 用途 | 必填 |
| --- | --- | --- |
| `DATABASE_URL` / 数据库相关变量 | 生产 MySQL 连接 | 是 |
| `JWT_SECRET_KEY` | 登录令牌签名 | 是 |
| COS 访问凭据及桶配置 | 头像、证书、工作室图片 | 是 |
| `TENCENT_MAP_KEY` | 管理后台浏览器端 JavaScript API GL 地图 | 使用地图时 |
| `TENCENT_MAP_WEB_SERVICE_KEY` | 服务端地点搜索、逆地理编码 | 使用地点搜索时 |
| 微信小程序 / CloudBase 认证相关变量 | 微信登录身份校验 | 是 |
| 首次管理员初始化变量 | 仅首次初始化时使用，完成后移除或禁用 | 按需 |

地图 Key 配置说明：

- `TENCENT_MAP_KEY` 使用启用 **JavaScript API GL** 的 Key，并在腾讯位置服务中将生产后台域名加入 Referer 白名单。
- `TENCENT_MAP_WEB_SERVICE_KEY` 使用单独启用 **WebService API** 的服务端 Key；不要复用浏览器 Key。
- 生产域名变更后，先更新腾讯位置服务的白名单，再发布服务。

### 2.3 数据库与对象存储

- [ ] 生产数据库已备份，并验证可以恢复到独立实例。
- [ ] 发布镜像启动时会执行数据库迁移；先在测试环境完整验证迁移。
- [ ] COS 桶、地域、CORS、读写权限符合生产策略；私有文件通过签名 URL 访问。
- [ ] 证书、头像、工作室封面上传和读取已在生产配置下验证。

## 3. 发布步骤

1. [ ] 冻结本次版本，记录 Git 提交和回滚版本。
2. [ ] 在测试环境完成第 1 节全部验证，并确认无 P0/P1 问题。
3. [ ] 备份生产数据库；确认迁移脚本和回滚方案。
4. [ ] 配置或复核第 2 节全部生产变量、域名和第三方白名单。
5. [ ] 构建管理后台，将 `admin-src/dist` 同步到后端的 `backend/admin-dist`。
6. [ ] 发布 CloudBase 云托管服务，等待新版本健康检查通过。
7. [ ] 调用生产健康检查接口：`GET /api/health`，确认 HTTP 200。
8. [ ] 使用生产管理员账号执行管理后台冒烟测试；使用真实或测试微信号执行小程序冒烟测试。
9. [ ] 确认云托管错误日志、数据库连接、COS 上传和地图服务无异常。
10. [ ] 发布/提交微信小程序审核；审核通过后发布正式版，并记录版本号与发布时间。

## 4. 上线后验收

- [ ] 管理后台首页、教师管理、工作室管理、小程序用户、账号权限、年审审核可用。
- [ ] 小程序首页、工作室列表与详情、教师查询、我的、证书、年审可用。
- [ ] 登录、头像同步、证书保存、工作室导航各完成一次真实验证。
- [ ] 重点 API 无 5xx；若有异常，记录 `requestId`、时间、用户操作和截图。
- [ ] 观察发布后 30 分钟的云托管日志、错误率和数据库连接情况。

## 5. 回滚方案

触发条件：核心登录/查询/证书/年审不可用、持续 5xx、数据迁移风险或严重数据错误。

1. [ ] 立即停止继续发布和数据写入操作。
2. [ ] 在 CloudBase 云托管中切回“回滚版本”记录的稳定版本。
3. [ ] 验证 `/api/health`、管理员登录和小程序首页。
4. [ ] 若涉及数据迁移，按已验证的数据库恢复方案执行；不要直接手工删除生产数据。
5. [ ] 导出相关 `requestId` 和日志，完成原因分析后再安排修复发布。
