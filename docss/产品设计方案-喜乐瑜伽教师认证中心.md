# 喜乐瑜伽教师认证中心 — 产品设计方案

> **版本**：V1.0  
> **日期**：2026年6月13日  
> **依据**：《需求调研-喜乐瑜伽教师管理小程序.md》V2.1、《技术选型报告-喜乐瑜伽教师管理小程序.md》v1.4、参考视觉稿 `desgin/design.png`  
> **范围**：第一期 MVP 产品设计，包含教师认证、年审管理、教师查询、瑜伽工作室基础展示与维护；不包含月度教学记录、资讯/课程 CMS、有赞深度集成、复杂分级授权。

---

## 1. 产品定位

喜乐瑜伽教师认证中心是一套面向 **教师资质管理、年审审批、公众查询** 的双端产品：

- **微信小程序**：服务学员与教师。学员查认证教师，教师查本人资质和年审状态。
- **PC 管理后台**：服务教师管理委员会。管委会维护教师资料、导入 Excel、查看年审数据、处理年审申请。

首期产品原则为：**后台维护基础信息，前台按权限查询展示**。这能减少教师端填报复杂度，也更符合 7 月底前测试上线的节奏。

## 6. 核心流程

### 6.1 学员查教师

1. 进入小程序首页。
2. 点击「教师查询」。
3. 输入姓名、喜乐名或编号。
4. 可按等级、地区、认证状态筛选。
5. 进入教师详情页，查看认证等级、有效期、常驻城市、证书预览。

异常状态：

- 无搜索结果：提示“未找到匹配教师”，引导更换关键词。
- 认证失效：教师卡片展示“认证已过期”，详情页强调有效期。
- 同名教师：列表展示城市、等级、编号，避免误认。

### 6.2 教师查看本人认证

1. 教师进入「我的」。
2. 系统通过 OpenID 判断是否已绑定教师身份。
3. 已绑定：展示本人认证卡、有效期、距到期天数。
4. 未绑定：展示绑定入口，输入邀请码或由管委会预置绑定。
5. 教师可进入年审记录或提交年审申请。

### 6.3 管委会处理年审

1. 管委会登录 PC 后台。
2. 首页查看待审数量与即将到期数量。
3. 进入「年审管理」待审核列表。
4. 查看教师资料与年审材料。
5. 选择通过或驳回，填写审核意见。
6. 通过后系统更新该教师认证有效期。

### 6.4 Excel 导入教师资料

1. 管委会进入「教师管理 / 批量导入」。
2. 下载或按约定模板整理 Excel。
3. 上传 Excel。
4. 系统预检字段、档位、日期、重复编号。
5. 展示预检报告。
6. 确认导入后写入教师台账并生成导入日志。

### 8.4 工作室字段

| 字段 | 说明 |

| 展示开关 | 管委会控制是否在小程序展示 |

## 9. 状态设计

### 9.1 认证状态

| 状态 | 判断方式 | 前台展示 |
|------|----------|----------|
| 认证有效 | 当前日期小于有效期，且未进入临期区间 | 绿色状态 |
| 即将到期 | 距有效期小于等于 90 天 | 金色提醒 |
| 已过期 | 当前日期大于有效期 | 灰色或警示状态 |
| 免审 | L5 或后台配置为免审 | 绿色状态，说明免审 |

### 9.2 年审状态

| 状态 | 说明 |
|------|------|
| 未提交 | 到期年度内尚未提交 |
| 待审核 | 教师已提交，管委会未处理 |
| 已通过 | 审核通过，有效期已更新 |
| 已驳回 | 需教师重新提交 |
| 免审 | 当前档位无需年审 |

## 10. 视觉设计规范

### 10.1 设计气质

关键词：**温和、可信、留白、认证感、轻东方、自然生活方式、适合瑜伽女性用户的精致感**。

小程序端偏柔和、轻盈、自然，避免政务化或“老年机”式的大块粗糙按钮；PC 后台偏克制，强调效率、数据密度和可扫描性。

### 10.2 移动端尺寸基准

小程序页面按当前主流手机宽度设计，原型画布采用 **390 × 844** 的全面屏比例，接近 iPhone 13/14/15 与主流 Android 小程序可视区。实际开发时按 `rpx` 响应式落地，关键内容需在 375～430px 宽度内保持可读、可点、不卡边。

### 10.3 色彩

| Token | 色值 | 用途 |
|-------|------|------|
| `--sage` | `#78887A` | 主按钮、选中状态、认证通过 |
| `--paper` | `#F7F4EE` | 页面背景、柔和底色 |
| `--gold` | `#B89A63` | 等级徽标、重点数字、临期提醒 |
| `--ink` | `#1F2521` | 标题、主要文字 |
| `--mist` | `#E8ECE9` | 分割线、弱背景 |
| `--rose-soft` | `#F4DED8` | 移动端柔和女性化氛围、轻量点缀 |

### 10.4 组件风格

- 圆角：移动端卡片 20-26px，后台卡片 8-12px。
- 阴影：移动端使用柔和漫反射阴影，营造轻盈感；后台保持轻阴影。
- 图标：线性图标，1.5px 视觉重量。
- 卡片：移动端使用暖白、半透明、轻玻璃感；后台使用白底、轻边框、宽松内边距。
- 状态标签：绿色表示有效，金色表示等级/提醒，灰色表示过期或弱信息。

## 11. 页面设计说明

### 11.1 小程序首页

目标：让学员快速进入教师查询，也让教师能看到自己的认证入口。

关键内容：

- 品牌标题：喜乐瑜伽教师认证中心。
- 主视觉：瑜伽练习场景，营造安静可信感。
- 主行动：教师查询。
- 次行动：我的认证、有赞学堂。
- 数据概览：认证教师总数、本年度完成年审。

### 11.2 教师查询页

目标：快速找到教师并判断资质。

关键内容：

- 搜索框：姓名 / 喜乐名 / 编号。
- 筛选：等级、地区、认证状态。
- 教师卡片：头像、姓名、喜乐名、城市、等级徽标、认证状态、有效期。

### 11.3 教师详情页

目标：展示可公开核验的信息。

关键内容：

- 头像、姓名、等级、认证状态。
- 概要信息表：喜乐名、编号、等级、认证时间、有效期、城市。
- 证书展示：缩略图，支持查看大图。
- 认证说明：提示该教师资质由教师管理委员会认证维护，不提供直接联系教师按钮。

### 11.4 我的认证页

目标：让教师知道自己当前状态和下一步。

关键内容：

- 顶部认证卡：姓名、等级、认证有效状态。
- 有效期与距到期天数。
- 我的档案、年审记录、证书查看、设置。

### 11.5 年审记录页

目标：让教师查看历次年审结果。

关键内容：

- 当前认证等级与有效期。
- 年审时间线：年度、提交时间、审核人、状态。
- 待审核/驳回状态需突出下一步动作。

### 11.6 瑜伽工作室列表

目标：让学员和教师找到官方认可的线下练习空间。

关键内容：

- 顶部氛围卡：展示“认证场馆”的产品心智。
- 搜索：城市、工作室名称、主理教师。
- 筛选：全部、城市、开放状态。
- 工作室卡片：图片、名称、城市区域、主理教师、开放状态。

### 11.7 工作室详情页

目标：说明工作室是否可信、在哪里、由谁负责。

关键内容：

- 工作室封面图。
- 认证状态、名称、城市区域。
- 主理教师与认证等级。
- 地址、开放时间、联系方式。
- 联系工作室按钮，首期可由统一客服承接。

### 11.8 管理后台数据看板

目标：管委会每天进入后台即可看到重点事项。

关键内容：

- 认证教师总数、待审人数、即将到期、本年度完成年审。
- 年审趋势图。
- 待处理事项。
- 最新认证教师。

### 11.9 教师管理

目标：维护教师台账。

关键内容：

- 搜索、等级筛选、地区筛选、认证状态筛选。
- 表格：编号、姓名、喜乐名、等级、地区、状态、有效期、操作。
- 操作：查看、编辑、导出、新增教师。

### 11.10 年审管理

目标：处理待审核申请。

关键内容：

- 待审核、已通过、已驳回分栏。
- 列表展示提交时间、教师姓名、等级、到期时间。
- 详情页展示教师资料、年审材料、审核意见、通过/驳回按钮。

### 11.11 工作室管理

目标：管委会维护小程序端展示的工作室资料。

关键内容：

- 工作室列表：名称、城市、主理教师、认证状态、展示状态、更新时间。
- 筛选：城市、展示状态、资料完整度。
- 新增/编辑：基础资料、封面图、地址、联系方式、主理教师关联。
- 展示控制：资料不完整时可暂停对外展示。

### 11.12 批量导入

目标：将现有 Excel 教师资料导入系统。

关键内容：

- 上传区。
- 模板下载。
- 预检结果：成功、警告、错误。
- 错误行定位与原因。
- 导入日志。

## 12. 验收标准

### 12.1 产品验收

- 学员能搜索教师并查看认证有效性。
- 学员能查看认证瑜伽工作室列表与详情。
- 教师能查看本人认证等级、有效期、年审状态，并提交年审申请。
- 管委会能导入教师资料、维护教师信息、维护工作室信息、查看年审看板、审批年审。
- L0-L3、L4、L5 的年审周期可配置，不写死在前端。
- 首期不出现月度教学记录、资讯/课程 CMS、复杂分级授权、工作室预约/支付入口。

### 12.2 设计验收

- 小程序端与参考图保持一致的温和认证中心风格。
- 后台端保持高信息密度但不拥挤，表格与审批操作清晰。
- 状态颜色一致：有效绿色、等级/提醒金色、失效灰色。
- 移动端关键按钮可单手点击，后台端表格可扫描。
